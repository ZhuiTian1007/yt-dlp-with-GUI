# Title

為強大的下載影片的開源工具yt-dlp專門寫的GUI介面。

## Usage

解壓縮後開啟`main.exe`就可以了。

## Background

每當想要下載YouTube影片時都會用yt-dlp下載，但yt-dlp沒有提供GUI，只能在cmd或PowerShell打指令使用。

若有特殊需求，還需到yt-dlp的Github查詢指令參數使用，實在有點麻煩。

所以想說自己會寫一點Python的Tkinter，藉此機會寫一個GUI，在訓練自己程式能力的同時，還多了一個小工具給自己和大家使用。
